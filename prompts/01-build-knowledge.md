# 01: Build the knowledge library

**Where to run:** Claude Code, started inside your project folder (`~/Documents/evoskill/email-campaigns`).

**What it does:** saves the writing and marketing advice Claude reads before every email into `knowledge/`.

```
Save each of these pages as a markdown file in the knowledge/ folder. Put the source URL at the top of each file and keep the full text.

- https://paulgraham.com/simply.html
- https://paulgraham.com/talk.html
- https://paulgraham.com/useful.html
- https://blog.ycombinator.com/how-to-email-early-stage-investors/
- https://blog.ycombinator.com/startup-school-week-4-recap-kat-manalac-and-gustaf-alstromer/
- [add your own links here]

Then search the web for:
1. A transcript of YC's talk "How to Convert Customers With Cold Emails" by Aaron Epstein.
2. The best articles on marketing, messaging and email from a16z (a16z.com and Andrew Chen's blog).
Save the 5 best results as markdown files in knowledge/ the same way.
```

Then copy in your own notes, for example `cold-email-principles.md` from `project-template/knowledge/`.
